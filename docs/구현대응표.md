# 보고서와 구현의 대응

| 보고서 요구 | 구현 | 적용 시 판단 |
|---|---|---|
| Windows 측정폴더 감시 | `pipeline.scan`, CLI watch, Windows 1분 예약 | 시간 트리거/폴링으로 실제 구현; 저장 안정화 및 이동 파일 지원 |
| Keithley XLS/XLSX/CSV | `ingest.py` | 첫 50행 헤더, 다중 시트, CP949, 명시 매핑, SI 단위 |
| 파일명 메타데이터 | `util.parse_filename`, vg/vgs 고정 조건 fallback | 누락 조건은 경고; 측정 시각 추측 안 함 |
| QC | `analysis.qc_branch`, hysteresis, invalid rows | Ig로 누설 계산; 미측정 항목 SKIP; 기준은 예시 |
| 모델 A/B | sinh, linear | 보고서의 `Iexp + V/Rs`는 식별 가능한 slope+offset으로 구현; 0 근처 slope에서 불안정한 역수 저항을 단정하지 않음 |
| RMSE/AIC/BIC 및 그림 | 그룹별 수치 테이블, 측정·피팅·잔차 PNG | 다른 조건/방향을 섞어 한 번에 피팅하지 않음 |
| ChatGPT JSON 해석 | OpenAI Responses HTTP, strict JSON schema | opt-in, 요약 수치 전달, 실패 시 수치 요약 |
| ChatGPT Work 언급 | 로컬 Python + API 또는 키 없는 수치 요약 | Work 자체를 외부 호출 가능한 API로 취급하지 않음 |
| Obsidian 연구노트 | `render.experiment_note` | 지정한 기존 Vault에 Markdown/첨부파일 생성 |
| 주간 집계 | `reports.weekly` | Asia/Seoul ISO 주, 완료시각, 재분석 중복 제거 |
| n8n/Docker | 인증 HTTP 서비스 + import JSON | 설치 선택 사항; Execute Command 권한/컨테이너 Python 가정 제거 |
| 에러/로그/재시도 | SQLite 상태, 제한 횟수, 회전 로그, 프로세스 잠금 | 불량 입력과 AI 실패가 정상 파일 처리를 중단하지 않음 |
| 데이터 보존 | 입력 SHA-256 스냅샷, 설정/코드 해시, 결과 이력 | 원본을 수정/이동하지 않음 |
| 백업 | DB online backup + ZIP + 파일별 manifest + archive checksum | 미처리 Inbox는 별도 백업 대상; 자동 삭제 없음 |
| 테스트·배포 | unittest 통합/회귀, pinned requirements, PowerShell | Linux에서 실제 검증; Windows와 실측 데이터 검증은 분리 |

이 프로그램은 측정파일 이후 단계의 자동화입니다. VISA로 SMU를 제어하거나 실험 조건을 자동으로 바꾸는 기능은 보고서의 파일 인입 범위를 넘어가므로 포함하지 않았습니다.
