# 실제 Template Creator 보고서 연결

1.7.0은 사용자가 제공한 `FET_Report_Template_v1.0.0.zip`의 Jinja·JSON Schema·빈 입력 계약을 기본 새 노트 생성 경로에 연결합니다. `science_exports.note`와 `comparison_catalog.publish`가 기존 계산·비교 결과를 작은 canonical view로 바꾼 뒤 렌더링합니다. 과거 노트는 갱신하지 않습니다.

원본 ZIP SHA-256은 `169aa97e25eb262b60947bf33c2ed71f0179220c4f2b1a3ad359f83bab6c506f`입니다. 원본 파일별 해시는 `research_automation/report_templates/fet_v1/source-manifest.json`에 보존했습니다. 앱 사본의 버전은 `1.0.0+hi.1`입니다. Library 다운로드 실패 후 사용자가 직접 저장한 실제 ZIP을 검증하고 사용했습니다.

## 수정한 형식과 연결

- 날짜·단위·광 조건을 추정에서 확인으로 바꾸지 않습니다. 메타데이터 값·출처·원래 상태·다른 근거를 접힌 표에 표시합니다. 기존 GUI의 별도 override 이력이 사용자 확인 저장소입니다.
- 근거 앵커의 밑줄과 원본 스키마 ASCII 패턴의 충돌을 고쳤습니다. 후보 수치마다 자신의 source/run/figure 연결을 검증합니다. 같은 모듈의 다른 그림이 그 수치를 승인하지 않습니다.
- 원본 사본의 SHA-256, 실제 PNG decoding·크기·해시, 해당 CSV 존재를 검사합니다. 이 검사는 인간 픽셀 검토나 과학적 승인과 다릅니다.
- IdVg/IdVd의 원래 곡선과 SS·gm·G의 계산 근거를 연결합니다. 원래 블록·방향에서 0에 가장 가까운 평가 전압의 기록된 예시를 선택하고 끝점을 먼저 선택하지 않습니다. 최대·평균으로 바꾸지 않습니다. 전체 기록은 원래 CSV와 schema 3 저장소에 남습니다.
- 단일 G·gds·정규화 gm은 일반 관측 영역에서 검토합니다. Drain-fold 전용 섹션은 구조 확인을 가정하지 않습니다. Output의 gate 단면은 transfer sweep이 아닙니다.
- 비교 프로필은 두 원본 곡선과 원래 조건의 일치/미확인을 표시합니다. 기존 비교 엔진이 허용한 쌍의 ΔId·Δ|Id|만 후보로 표시합니다. 새 보간·비율·평균·광 파워 추정은 하지 않습니다. 범위 차이는 crop으로 해소하지 않습니다.
- 전체 결과 `tojson` 중복을 없애고 작은 추출 기록·원본 셀/행 링크를 남겼습니다. 긴 배열은 기존 저장소에 연결합니다. 핵심 수치는 최대 3개, 다음 행동은 1개입니다.
- HTML 미리보기가 표준 Markdown 이미지·한글/공백 링크·상세 앵커·접기를 지원합니다. 실제 Obsidian renderer와 구분합니다.

## 계산과 저장 계약

7필드 metric contract와 schema 1/2/3 lossless reader를 사용합니다. 어댑터는 계산식·QC 문턱·추출 파일의 값과 availability를 수정하지 않습니다. SI 가정값·검출한계·미확인 지표를 확인 수치로 승격하지 않습니다. RR 방향, ΔG/AG 정의, gm 부호·끝점·평활 민감도는 기존 분석에 따릅니다. 확인되지 않은 값은 null과 사유를 보존합니다.

근거 그림이 없으면 그 수치를 표시 보류하고 기존 후보 기록은 삭제하지 않습니다. 템플릿 리소스도 코드 fingerprint에 포함합니다. Jinja2·jsonschema·템플릿 파일을 일반 설치와 휴대용 패키지에 포함합니다.

## 검증과 범위

프로젝트 전체 검증 명령은 `python -m unittest discover -s tests -v`입니다. 템플릿 전용 테스트는 합성 입력을 명시하며 실제 연구자의 확인으로 사용하지 않습니다. 실제 IdVg·IdVd 사본은 단위 미확인 상태이므로 확인 수치 0개인 상태로 검증합니다. 실제 입력 사본의 해시와 기존 계산 값은 유지합니다.

로컬 Chrome HTML QA에서 IdVg 7개·IdVd 2개·비교 2개의 PNG 로딩, 로컬 링크, 근거 접기, 390px 화면을 검사했습니다. 스크린샷과 실제 데이터 QA 산출물은 작업 폴더에만 저장하며 공개 소스에 포함하지 않습니다. 실제 Obsidian 화면은 미검증입니다. Windows 전체 테스트와 ZIP 실행의 최종 결과는 별도 배포 결과 문서에서 확인합니다.
