# 1.4.0 계산 기준과 설정

설정은 활성 `config.json`입니다. `config.example.json`은 기본값 참고용입니다. 이전 설정에 없는 `science` 필드는 읽을 때 보완하고 GUI 저장 시 기록합니다. 수치 설정·단위 배율 변경은 새로운 선택 분석이며, 확인 메타데이터만 바꾸면 수치 계산을 재사용합니다. 기본값은 연구실의 검증된 물리 기준을 의미하지 않습니다.

## 메타데이터

`research_context.fields`의 각 항목은 `value`, `unit`, `source`, `status`, `candidates`, `history`입니다. 상태는 confirmed/inferred/missing/conflict입니다. unknown은 값이 없는 상태입니다. 파일명 light/withlight/dark 및 폴더 날짜는 inferred, GUI 확인은 reason/researcher/time을 갖는 user_override입니다. 소자 폴더 이름은 자유 문자열입니다.

사용자가 실제 측정일을 확인하면 장비 Last Executed와 구별해 저장합니다. 장비 시각은 시간대/장비 시계 미확인 기록이며 실제 측정일의 동등한 후보가 아닙니다. 실제 시간은 별도 확인 전까지 unknown입니다. 장비 delay 0 s와 파일명/사용자 0.1 s는 override 저장 후에도 conflict입니다. 출처 불일치를 사용자 확인값 하나로 덮어버리지 않습니다. 광 표기는 이유 있는 사용자 확인으로 해소할 수 있으며 원래 후보와 불일치 이력은 남습니다.

확인 파일은 Vault의 `ResearchAutomation/metadata-overrides.json`입니다. 키는 Inbox 상대 경로와 원본 SHA-256으로 구성해 PC 사용자 절대 경로에 의존하지 않습니다. 다른 PC에서도 Inbox 상대 구조와 같은 내용의 파일이 필요합니다. 원본이 없으면 다른 PC 절대 스냅샷을 대신 읽어 잘못 갱신하지 않습니다.

`acquisition_metadata`와 각 group의 `original_sweep`에 uncropped start/end/min/max/step, Settings의 programmed start/end/step, 고정 전압, 방향, sweep/block/branch ID를 남깁니다. programmed 전압은 실제 측정 전압이라는 의미가 아닙니다. 측정 여부가 명시되지 않은 내보낸 전압은 exported_voltage_unconfirmed입니다.

legacy `qc` 문턱(점프50 nA, 누설/offset/히스테리시스100 nA)은 호환 경고입니다. 새 과학적 확인을 보장하지 않습니다. 측정되지 않은 Ig를 0으로 만들지 않습니다. offset은 signed 평균과 반복 표준편차를 기록하며 독립 반복이 없으면 불확실성 null입니다. 히스테리시스는 대응 방향의 공통 범위/단위가 기록되고 중복 전압·결측·reset을 넘는 경우 보류합니다.

실제 compliance flag와 설정 근접은 점별 별도 플래그입니다. 후자는 장비 compliance 확정이 아닙니다. 영향을 받는 점은 원본/사본에서 유지하고 RR·미분·적합 적합성에서 제외합니다. 부호 전환·국소 급변은 검토 후보이며 자동 이상치 삭제나 baseline 차감은 하지 않습니다.

## RR와 전도 지표

`RR(u,Vg)=abs(Id(+u))/abs(Id(-u))`. RR<1을 유지합니다. 정확 측정점 우선, 보간은 같은 segment에서 유효한 두 인접점만 사용합니다. 같은 전압의 서로 다른 전류 반복은 ambiguous이며 평균하지 않습니다. 범위 밖·결측·compliance를 연결하지 않습니다.

검출한계 D가 근거와 함께 설정된 경우:
- 분모 <D, 분자 ≥D: lower_bound = 분자/D.
- 분자 <D, 분모 ≥D: upper_bound = D/분모.
- 양쪽 <D: unavailable.
- D 미확인, 분모0: unavailable; 아주 작은 유한 분모는 numerical candidate이며 검출한계 미확인을 명시합니다.

각 지표는 u/Vg, 방향·블록, 원본 전류·행·셀, 보간 여부, 상태·사유·단위를 갖습니다. 단위가 미확인일 때 수치 value는 null이고 `candidate_value_assuming_si`에 계산 후보를 남깁니다. `metrics.csv`의 legacy RR에도 평가 전압이 명시됩니다.

signed Id/Ig, I/V, dI/dV는 별개입니다. V=0의 I/V는 unavailable입니다. 영전압 지역 기울기 역수는 **유효 미분저항**이고 독립 noise 모델이 없으면 불확실성을 추정하지 않습니다. 접촉저항으로 바꾸지 않습니다.

## gm·Vth·SS·이동도

raw 미분은 실제 좌표에서 numpy gradient를 사용하고 경계는 일방 차분임을 기록합니다. 반전/결측/compliance는 segment 경계이며, duplicate 좌표의 양쪽 값을 임의 평균하지 않습니다. 국소 다항식은 점별 실제 전압을 중심으로 적합하고 각 창의 사용 점 수·경계 제외·미분을 기록합니다. 내부 peak는 일방 경계 창을 제외하고 두 개 이상의 지원 창에서 비교합니다. 위치/진폭 민감도 또는 Id 부호 전환은 ambiguous입니다. 지원하지 못한 창은 따로 표시합니다.

raw peak abs 값, signed gm, Vg, endpoint 여부와 내부 후보가 별도 필드입니다. gm/max(abs(gm))와 abs(gm)/max(abs(gm))는 무차원, gm/Vd는 A/V²이고 Vd=0은 unavailable입니다. 전류 max/min은 측정 구간 비율이고 on/off ratio가 아닙니다.

선택 설정 예시(값은 합성 설명용이며 실측에 그대로 적용하지 마세요):

```json
{
  "detection_limit_a": 1e-12,
  "detection_limit_evidence": "별도 baseline 측정으로 연구자가 확인한 근거",
  "vth": {"method":"constant_current", "criterion_a":1e-8, "window_v":[-20,20]},
  "ss": {"window_v":[-20,-5], "current_range_a":[1e-11,1e-8]},
  "mobility": {"confirmed":true, "linear_regime_confirmed":true, "L_m":1e-6, "W_m":5e-6, "Cox_f_per_m2":1e-4}
}
```

위 항목은 `science` 객체 안에 넣습니다. Vth는 specified current 이상 검출과 유일한 crossing, SS는 검출한계 위·연속·비중복·동일 부호·단조 창의 log10(abs(Id)) 적합을 요구합니다. SS는 V/dec이고 mV/dec로 표시하려면1000배입니다. geometry나 확인된 선형 동작 조건이 없으면 이동도만 unavailable입니다. 계산하더라도 **2-terminal apparent field-effect mobility**, m²/(V·s)이며 접촉 효과가 남습니다.

## 비교·전환점

확인된 동일 소자, 전극/극성, delay/hold/pre-bias, 이력, 환경, 단위가 필요합니다. 실제 날짜가 같다는 것만으로 같은 이력을 가정하지 않습니다. 원래 측정/장비 설정 범위·step·방향·블록·순서가 다르면 비교 보류 이유를 표시합니다. Id–Vd의 전체 gate step 범위도 확인해 동일 Vg 하나를 골라 ±20/±40 조건 차이를 숨기지 않습니다.

RR 감소→완만 전환점은 연속 두 구간 회귀 후보입니다. argmin이 아닙니다. 두 기울기·양쪽 점 수·single-line 대비 개선·양 끝 제거와3점 median 민감도를 남깁니다. 두 번째 기울기가 첫 번째 크기의60% 이상이거나 감소→완만 구조가 없거나 개선이15% 미만이면 no_knee입니다. 높은 잔차/민감도는 ambiguous입니다. 이 수치 기준은 구현 기본 판단이며 물리 전환 인증이 아닙니다. 전류 검출한계 bound는 knee 점으로 쓰지 않습니다.

dark/light 비교에서 signed ΔId와 Δabs(Id)를 별도 저장합니다. 광파워가 확인된 양수 W일 때만 signed ΔId/P 후보(A/W)를 제공하며, 없는 경우 null입니다. 빛에 의한 물리 효과별 기여를 자동 분해하지 않습니다.

## 선택 정류 모델

u=abs(Vd), j=abs(Id), `j=j0*exp(u/a)`와 `u=Rs*j+a*ln(j/j0)`를 사용합니다. 로그 내부는 무차원입니다. 양·음 분리 지수 기준선 k=4, 양·음 독립 series k=6, 공통 a/j0·별도 Rs k=4, 공통 a·별도 Rs/j0 k=5입니다. 공통 jref와 같은 유효점에서 **전류 영역** 손실을 최소화합니다.

각 극성의 높은 전압20%를 holdout으로 남기고, 전류 RMSE·극성별 잔차·점 수·초깃값·경계·수렴·SVD 조건/계수 상관·범위 변경 민감도를 출력합니다. 경계 접근은 unstable, 약한 식별성은 poorly_identified입니다. 상관 잔차에 iid 신뢰구간을 적용하지 않아 CI는 null입니다. 추가 계수의 낮은 훈련 RMSE만으로 승자를 고르지 않습니다.

Rs[ohm]는 유효 계수, a[V]는 전압 척도, j0[A]는 전류 척도입니다. 접촉저항·전류 경로 비율·장벽·이상계수로 자동 해석하지 않습니다. 모델 활성화 후 설정 저장·대표 파일 선택 분석으로 검증하세요.
